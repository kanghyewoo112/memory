# 마음서랍

> 내가 살았던 순간을, 내가 기억하는 방식으로, 내 목소리로.

마음서랍은 사용자가 들려준 기억 하나를 그 사람의 말투와 사진, 목소리로 엮어 **1분 영상 자서전**으로 만드는 서비스입니다. AI가 인생을 대신 쓰지 않고, 말하지 않은 사건·감정·대사는 넣지 않습니다.

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 소개(홍보) 페이지 |
| `studio.html` · `studio.js` · `studio.css` | 1분 자서전 제작 스튜디오 |
| `styles.css` | 공통 디자인 |
| `images/` | 배경 사진 (Unsplash 무료 라이선스) |
| `presenter.mp4` | 소개 페이지 예시 영상 |

## 스튜디오 제작 흐름

1. **기억 고르기**: 한 서랍에는 한 기억만 담습니다.
2. **기억 인터뷰**: 질문을 한 번에 하나씩 합니다(사람·장소·시간·장면·감각·말). 기억나지 않는 칸은 비워 둡니다.
3. **사진 확인**: 사진 속 인물·장소·시기를 사용자가 아는 만큼만 적습니다.
4. **대본·녹음**: 들려준 말만으로 1분 구조(0–8 / 8–20 / 20–42 / 42–52 / 52–60초)를 엮고, 구간별로 본인 목소리를 녹음합니다.
5. **검증**: RED·SILVER·BLUE 자동 점검과 GOLD(사람의 반응)로 판정합니다. 합격 기준은 9.7점 이상입니다.
6. **완성**: 제목, 기억 한 줄, 내레이션, 장면 구성표, AI 재현 설명, 필요한 자료를 담은 제작 의뢰서를 내려받습니다.

## 실행

빌드 과정이 없습니다. `index.html`을 브라우저로 열거나, 정적 호스팅(GitHub Pages 등)에 그대로 올리면 됩니다. 녹음과 음성 입력은 https 주소에서 가장 잘 동작합니다.

작성한 기억과 사진, 녹음은 사용자 브라우저(IndexedDB)에만 저장되고 서버로 보내지 않습니다.
